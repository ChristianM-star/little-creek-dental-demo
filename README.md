# Little Creek Family Dental — Concept Redesign

Standalone, client-facing static demo extracted from the earlier builder-generated concept.

This version intentionally contains no Lovable branding, metadata, favicon, or runtime hooks. It uses a custom LC mark and a dependency-free HTML/CSS implementation.

## Run locally

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.
